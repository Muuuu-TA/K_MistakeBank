# K_MistakeBank 错题复习提醒器 · 使用说明

一个**单文件、纯前端、无后端**的错题本工具。所有代码（HTML + CSS + JS）都在 `K_MistakeBank.html` 一个文件里，零依赖、不加载任何外部框架或 CDN，双击就能用。

核心思路是**间隔重复（Spaced Repetition）**：每道题有自己的复习间隔，答对就拉长间隔，答错就归零重来，让快要忘记的题自动出现在「今日复习」里。

## 一、快速开始

### 方式 A：直接打开（最省事）

双击 `K_MistakeBank.html`，用 Chrome / Edge / Safari 打开即可。

> ⚠️ 这种方式地址栏是 `file://`，部分浏览器会**禁用 IndexedDB**，此时题目图片会自动降级存到 localStorage（容量只有 5 MB 左右，图片多了容易满）。设置页顶部会有橙色提示告诉你当前是否处于降级状态。

### 方式 B：用本地服务器打开（推荐）

在项目目录里执行任意一条，然后浏览器访问提示的地址（通常是 `http://localhost:8000`）：

```bash
# Python（自带，无需安装）
python -m http.server 8000

# Node.js
npx serve .
```

这样 IndexedDB 可用，图片存储容量大得多，也能启用「备份到我自己选的文件夹」功能。

### 首次使用建议

1. 进「设置」→「复习科目」，添加你自己的科目（也可以先跳过，新增错题时手输会自动收录）。
2. 进「设置」→「每日目标」，把「每日复习题数」调成你实际能完成的量。
3. 回到「错题本」→「➕ 新增错题」，录 2～3 道题试试流程。

## 三、日常使用流程

### 1. 录入错题

「错题本」→「➕ 新增错题」，填写：

- **科目**：可从下方快捷标签点选，也可手动输入（新科目会自动收录进设置）。
- **题目简述**：必填，**不限字数**，可换行。
- **答案简述**：选填，不限字数。
- **错因标签**（五选一）：手滑 / 概念不清 / 没思路 / 公式记错 / 计算失误。
- **题目图片 / 答案图片**：选填。选择后会自动用 Canvas 压缩到**最长边 1280px、JPEG 质量 0.8** 再保存，不会把手机存储撑爆。

### 2. 用 AI 补答案和解析（可选）

填好题目后点「🤖 AI 错题分析」，会返回：

- **答案**
- **🧭 思路解析**：从已知条件出发怎么一步步想到答案，讲清突破口、所用方法与易错点（200–400 字）
- **📌 涉及知识点**
- **最可能的错因** + **下一步建议**

确认无误后点「一键填入」，答案、解析、知识点、错因标签会一次性写入表单。

> 有题目图片时会**连同图片一起分析**（自动再压到 1024px 控制体积）；没图就只分析文字。详见 [AI 相关说明](#ai-相关说明)。

### 3. 每天复习

进「今日复习」，只显示**到期（复习日期 ≤ 今天）**的题，按日期升序排列。

每张卡片默认只显示：科目、题目、错因标签、题目图片（答案先藏着，逼自己先想）。

- 点「**看答案**」展开答案、思路解析、知识点、答案图片。
- 「**会了**」：间隔升一级，下次复习日期按 `[0, 1, 3, 7, 15, 30]` 天顺延。
- 「**还不会**」：间隔归零，**明天**再来。

全部清空后显示 🎉「今日已清空」。

### 4. 自测模式

「今日复习」页顶部或「错题本」页有「🎲 自测」按钮：随机抽题、先遮答案，自评后会了 / 还不会，直接驱动上面的间隔算法。适合碎片时间刷题。

## 四、各页面详解

### 📅 今日复习

- 顶部环形进度：今天已复习 / 每日目标题数。
- 右上角红色角标 = 待复习数量。
- 卡片左侧色条表示紧急程度（红 / 黄 / 橙）。
- 答对 / 答错都会记入统计，并参与连续打卡与成就判定。

### 📒 错题本

- 顶部「➕ 新增错题」按钮。
- **按科目筛选**下拉 + **关键词搜索**框（搜题目文字），两者可叠加。
- 点任意卡片进入**编辑模式**：改文本、换错因标签、重新上传或删除图片、删除整道错题。
- 有思路解析的题目会带「🧭 有解析」标记。
- 删除错题会**同步删除** IndexedDB 中对应的图片，不会留垃圾数据。

### 📊 统计

- **专注与打卡**：连续打卡天数、最长纪录、最近 **35 天热力图**（颜色越亮当天复习越多）。
- **掌握进度**：各科待复习数、已掌握数（间隔指数 ≥ 3 视为掌握）、总复习次数、连续答对次数，配进度条与答对率。
- **错因分布**：五种错因各占多少，帮你定位到底是「手滑」还是「概念不清」。
- **成就墙**：17 个成就 + 积分段位（初心 → 进阶 → 熟练 → 达人 → 大师 → 传说）。

### 🏫 校内服务（CQU 校内服务引导）

- **一、常用网站网址链接**（18 个）：点击直接跳转新窗口。
- **二、常用微信公众号**（13 个）：**点一下复制名称**，再到微信里搜索添加。
- **三、常用 APP**：今日校园，**点一下复制名称**。
- **四、常用部门电话**（13 个部门共 28 个号码）：**点一下复制号码**，自行粘贴到拨号盘（不会直接拨号）。

顶部有搜索框（支持搜网站名 / 公众号 / 号码 / 部门名）和分类 Tab（全部 / 网站 / 公众号 / APP / 电话）。

> 提示：智慧教务、一卡通、校园网自助等系统通常需在校内网或学校 VPN 环境下访问。

## 五、设置页详解

### 🤖 AI 增强

- **AI 错题分析开关**（默认开启）。关掉后新增/编辑页不显示分析按钮。

#### AI 相关说明

| 项目 | 说明 |
|---|---|
| 文字分析 | Pollinations `openai-fast`，免注册 |
| 读图分析 | OVHcloud `Qwen2.5-VL-72B-Instruct`，免注册、支持 base64 图片 |
| 降级机制 | 视觉接口繁忙或失败时，自动改为纯文字分析，并在结果卡片上标注 |
| 解析容错 | 会自动清理 ` ```json ` 标记后再解析；仍失败则显示原始文本并提示「AI返回格式异常」 |
| 请求中 | 按钮进入 loading 并禁用，防重复点击 |
| 网络失败/超时 | 提示「免费AI服务暂时不可用，请稍后重试或手动填写。」 |

> ⚠️ 免注册视觉接口有频次限制（约 **2 次/分钟/IP**），连点容易触发降级提示——这是预期行为，不是故障。稍等一分钟再试即可。

### 🍅 番茄钟时长

四个数值都可以**直接点数字框手动输入**，也可以用旁边的 −/＋ 微调（超出范围会自动夹到最近的合法值）：

| 项目 | 范围 | 默认 |
|---|---|---|
| 专注时长 | 1–180 分钟 | 25 |
| 短休时长 | 1–60 分钟 | 5 |
| 长休时长 | 1–90 分钟 | 15 |
| 长休间隔 | 每 2–10 轮 | 4 |

四组快捷预设：**经典 25/5**、**长专注 45/10**、**考研 50/10**、**碎片 15/3**。

右下角 🍅 悬浮按钮点开番茄钟面板，支持：

- **时间戳驱动**：切后台、锁屏、刷新页面都不会走偏。
- 暂停 / 继续 / 跳过 / 重置。
- 结束时 Web Audio 提示音 + 桌面通知，并自动切换到休息。
- 专注时长累计进统计页。

### 🎯 每日目标

| 项目 | 范围 | 步长 | 默认 |
|---|---|---|---|
| 每日复习题数 | 1–500 道 | 5 | 20 |
| 每日专注分钟 | 5–960 分钟 | 10 | 60 |

「每日复习题数」是今日复习环形进度的分母。

> 两项同样支持直接输入数字（步长只影响 −/＋ 每次跳多少）。手动输入时如果超出范围会自动夹到边界值，例如题数填 999 会被改成 500。

### 📚 复习科目

自由添加 / 删除科目，另有 14 个常用科目可一键添加。科目会作为新增错题时的候选（下拉 + 快捷标签）；手输的新科目在保存时会自动收录进来。

### 🎧 环境音

Web Audio 实时合成，不加载音频文件：白噪音 / 雨声 / 低频嗡鸣，可拖音量条。

### 💾 存储与备份 / 🗂️ 数据管理

见下一节。

### 🔌 自定义接口（可选）

留空则使用上面的免费接口。若你有更稳定的服务（任何 OpenAI 兼容端点），可填 Base URL、模型名、API Key（**仅保存在本机**，不会上传到任何地方）。

## 六、数据存储与备份

### 数据存在哪

- **文本**（错题、设置、日志、成就、番茄钟）→ **localStorage**
  默认键名：`en_items` / `en_settings` / `en_log` / `en_ach` / `en_timer`
- **图片** → **IndexedDB**
  默认数据库 `errorNotebook`，store `images`，以 **Blob** 保存，key 为 uuid。

两者都在**浏览器自己的沙箱**里，网页 JS 拿不到磁盘目录的写入权限，所以无法把 localStorage 指向 `D:\我的错题` 这种自定义路径。真实文件位置（仅供参考，不建议手改）：

| 浏览器 | 位置 |
|---|---|
| Chrome（Windows） | `%LOCALAPPDATA%\Google\Chrome\User Data\<配置>\Local Storage\leveldb` 与 `…\IndexedDB\` |
| Edge（Windows） | `%LOCALAPPDATA%\Microsoft\Edge\User Data\<配置>\…` |
| Firefox（Windows） | `%APPDATA%\Mozilla\Firefox\Profiles\<配置>\storage\default\<来源>\`（`ls` = localStorage，`idb` = IndexedDB） |
| Safari（macOS） | `~/Library/Safari/LocalStorage/`、`~/Library/WebKit/` |

最快的查看方式：**F12 → 应用（Application）→ 存储（Storage）**。这些是 LevelDB / SQLite 二进制文件，直接手改或删除**可能损坏整个浏览器数据**。

### 设置页能改的"路径"

既然改不了真实磁盘路径，能改的部分都开放了（设置 → 💾 存储与备份）：

| 功能 | 说明 |
|---|---|
| **当前存储位置** | 实时显示键名与库名，可一键复制 |
| **占用统计** | 文本多少 KB / 几个键，图片多少张多少 MB |
| **文本命名空间** | 键前缀，默认 `en_`，可改成 `kaoyan_`、`qimo_` 等。改前缀 = 换一个数据文件夹，同一浏览器可**并存多套数据** |
| **图片库名 / Store 名** | `errorNotebook` / `images` 都能改，迁移时把旧库图片全部搬过去再删旧库 |
| **图片存储后端** | IndexedDB（Blob，容量大）⇄ localStorage（base64，兼容差环境）双向迁移。转换失败会**取消切换**，不会静默丢图 |
| **备份到我自己选的文件夹** | 点「选择文件夹」授权后，可直接写 `错题备份_日期.json` 到你选的目录，也可开启「保存错题时自动备份」（最多每分钟一次） |
| **完整备份 / 恢复** | 导出**含图片**的 JSON（图片转 base64 内嵌）；恢复时可选「覆盖」或「追加合并」，且不会覆盖你当前的存储位置设置 |
| **导出 JSON / Markdown** | 「数据管理」里另有纯文本导出（不含图片）与复习清单（Markdown） |
| **清空全部数据** | 需二次确认，同时清空 localStorage 与 IndexedDB |

> 「备份到我自己选的文件夹」依赖 File System Access API，仅 **电脑版 Chrome / Edge + https 或 localhost** 支持；不支持时按钮会说明原因，可改用「完整备份」下载到默认下载目录。

### 换电脑 / 换浏览器

数据跟着**浏览器 + 来源（域名）**走，不跟文件走。迁移步骤：

1. 原机器：设置 → 存储与备份 →「💾 完整备份（含图片）」，得到一个 JSON。
2. 新机器：打开 `K_MistakeBank.html` →「♻️ 从备份恢复」→ 选择该 JSON → 选「覆盖」。

建议每月备份一次，尤其是以 `file://` 方式使用时（清浏览器缓存就容易丢）。

## 七、常见问题 / 注意事项

**Q：为什么图片存不进去 / 提示降级？**
多半是以 `file://` 双击打开导致 IndexedDB 被禁用。改用本地服务器打开（见 [快速开始](#方式-b用本地服务器打开推荐)）即可。

**Q：AI 分析一直失败？**
免费接口依赖网络可达性，且视觉接口约 2 次/分钟/IP。稍等重试；或到「设置 → 🔌 自定义接口」填你自己的 OpenAI 兼容端点。

**Q：换了一台电脑，数据没了？**
数据是存在浏览器里的，不是存在 HTML 文件里。请用「完整备份 / 恢复」迁移，见上一节。

**Q：能多人共用 / 多设备同步吗？**
不能。这是纯前端单文件应用，没有后端，数据只在本机浏览器里。

**Q：清空数据能后悔吗？**
不能。「清空全部数据」需要二次确认，且会同时清掉 localStorage 与 IndexedDB。操作前请先做一次「完整备份」。

**Q：题目和答案有字数限制吗？**
没有。题目简述与答案简述都不限字数，支持换行显示。

**Q：手机上显示正常吗？**
已针对移动端适配：底部 Tab、安全区留白（`env(safe-area-inset)`）、弹层高度用 `dvh`（避开 iOS 地址栏高度抖动）、毛玻璃降级、`prefers-reduced-motion` 保护。

### 快捷键 / 小技巧

- 复制类按钮（公众号名、电话号）支持键盘聚焦后按 **Enter / 空格** 触发。
- 搜索框输入时焦点不会丢失，可连续输入。
- 图片点一下可放大查看。

### 技术规格

- 单文件，约 128 KB，**零依赖、无框架、无 CDN、无后端**。
- 所有文案为中文。
- 图片上传后统一压缩（最长边 1280 / JPEG 0.8，白底防透明变黑）；显示走 `URL.createObjectURL` 并缓存，删除或替换时调用 `revokeObjectURL` 释放内存。
- 复习间隔数组：`[0, 1, 3, 7, 15, 30]` 天；间隔指数 ≥ 3 视为「已掌握」。
